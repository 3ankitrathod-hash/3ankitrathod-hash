# Global Social Media Analytics

## Overview
A SQL-focused group project presented as an analysis of a global social-media dataset. The presentation describes a relational structure for users, posts, likes, comments, followers, hashtags, and post-to-hashtag relationships.

## SQL concepts covered
- JOINs across related tables
- GROUP BY and aggregate functions
- ORDER BY for ranking results
- LEFT JOIN for retaining records with no matching activity
- NOT EXISTS and subqueries
- Date functions and engagement summaries

## Business questions described
- Which users or creators are most active?
- Which posts receive the most likes?
- How does engagement vary by country?
- Which hashtags appear most often?

## Data and reproducibility
The presentation file is not yet included in this project folder, and a standalone SQL query file has not yet been verified. To make this project reproducible, add reviewed SQL queries and a synthetic or properly licensed dataset/schema, plus instructions for running the queries.
