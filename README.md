## My analysis workflow

1. Define the business question and metrics.
2. Check data types, missing values, duplicates, and invalid values.
3. Clean and validate the data.
4. Analyze trends and segments using Python or SQL.
5. Communicate findings with clear charts and practical recommendations.
6. State limitations and validation status honestly.
